OUTPOST: NEW HOPE 2.0  by LordDeTracy
A modern rebuild of Sierra's 1994 game Outpost (version 1.51).
https://github.com/LordDeTracy/outpostnewhope

HOW TO PLAY
  1. Unzip this folder anywhere.
  2. Double-click "Play Outpost New Hope.bat".
     Saved games go in the "saves" folder.

  Windows 10 or 11, 64-bit. Nothing else to install.
  The game opens full screen: F11 or Alt+Enter switches to a window.

CONTROLS
  Enter / Ctrl+T     run a turn          F5          run several turns
  Click a building   open its window     Right-click its menu
  Alt+0..4, PgUp/Dn  change level        G           planet and sites
  Arrow keys         scroll              Mouse wheel zoom
  Ctrl+S             save                F1          help
  Esc                skip a movie / close a window
  Alt+X              exit

WINDOWS SAYS "WINDOWS PROTECTED YOUR PC"
  The game is not code-signed. Click "More info", then "Run anyway".
