# OutpostHD art

The building, robot and terrain pictures in this folder come from
OutpostHD (https://github.com/OutpostUniverse/OPHD), copyright 2015-2020
Leeor Dicker and contributors, graphics by White Claw, distributed under
the BSD 3-Clause License (LICENSE-OutpostHD.md). They are used unchanged.
The rebuild draws them in place of the original game's bitmaps
(src/app/hd_sprites.cpp maps the original building types to them).

`sfx/click.ogg` is OutpostHD's interface click (from the same release, same
licence); the rebuild plays it when a button, box or menu command is chosen.
